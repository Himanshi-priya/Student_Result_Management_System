# Student Result Management System using Arrays

## 1. Project Title
**Student Result Management System using Arrays**

## 2. Objective
The project stores and manages student result records using an array of structures in C. It supports:
- Student record entry
- Display of all records
- Search by roll number
- Update of a student record
- Deletion of a student record
- Calculation of total and average marks
- Identification of topper
- Generation of a simple result report

## 3. Technology Used
- Language: C
- Data structure: Array of structures
- Compiler: GCC / Code::Blocks / VS Code with a C compiler

## 4. Assumptions
- Maximum students = 100
- Number of subjects = 5
- Each subject is out of 100 marks
- Roll number is unique

## 5. Files
- `main.c` – complete source code
- `algorithm.md` – algorithm
- `flowchart.md` – flowchart
- `report.md` – brief project report
- `sample_output.txt` – sample execution

## 6. How to Run in VS Code
1. Open this folder in VS Code.
2. Make sure a C compiler such as GCC is installed.
3. Compile `main.c`.
4. Run the generated executable.
5. Use the menu to add, display, search, update, delete records and generate the report.

## 7. GitHub Upload
Open the folder in VS Code → Source Control → Initialize Repository → sign in to GitHub → Publish to GitHub.

## 8. Learning Outcomes
This project demonstrates arrays, structures, functions, searching, updating, deletion, loops, conditional statements, and menu-driven programming in C.
