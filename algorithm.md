# Algorithm

1. Start the program.
2. Create an array of structures to store student records.
3. Display a menu with operations:
   - Add
   - Display
   - Search
   - Update
   - Delete
   - Topper
   - Report
   - Exit
4. For **Add**, read roll number, name and five subject marks and store the record in the array.
5. For **Display**, traverse the array and print every student record.
6. For **Search**, compare the entered roll number with every record and display the matching record.
7. For **Update**, find the student by roll number and replace the name and marks.
8. For **Delete**, find the record and shift all later records one position to the left.
9. For **Total**, add all five subject marks.
10. For **Average**, divide total marks by five.
11. For **Topper**, compare student averages and select the highest average.
12. For **Report**, display all students with total and average and calculate the class average.
13. Repeat the menu until the user selects Exit.
14. Stop.
